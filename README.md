# GenAI Practice

A hands-on repository for learning and experimenting with **Generative AI (GenAI)** concepts, tools, and applications.

This project explores LLMs, prompt engineering, AI APIs, model integration, and building intelligent AI-powered applications.

### Topics Covered
- Large Language Models (LLMs)
- Prompt engineering
- Generative AI APIs
- Model integration and inference
- AI-powered application development
- Exploring GenAI frameworks and tools

**Goal:** Build a strong foundation in Generative AI through practical experiments and hands-on projects.
